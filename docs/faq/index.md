# 常见问题

本栏目收录当前项目中已有明确依据的常见问题，适用于仓库现有源码与配置。正式服务器部署问题将在相应流程验证后补充。

## 按现象查找

| 分类 | 常见现象 |
| --- | --- |
| [启动与配置](./startup.md) | 写了 .env 不生效、数据库或 Redis 连接失败、端口变化、接口文档找不到 |
| [登录与权限](./authentication.md) | 引导开关不能重置密码、验证码失效、登录成功未跳转、菜单和接口权限不一致 |
| [构建与代码更新](./build-deployment.md) | pnpm 版本不一致、依赖下载超时、修改源码后仍运行旧代码 |

## 建议排查顺序

1. 确认当前目录、Git 版本、实际运行的应用和访问地址。
2. 查看启动日志中的第一个有效错误，区分编译失败、启动失败和请求失败。
3. 请求失败时，查看浏览器 Network 中具体请求的 HTTP 状态和响应；不要只看页面提示。
4. 按对应条目核对运行配置、请求链路或权限，不反复重装依赖、重置密码或清空数据。
5. 修改后按实际运行方式重新加载，再检查原来的现象是否消失。

本文的“核对结果”是读者处理后的检查目标，不表示每台机器都已经实测。首次使用请先阅读[快速开始](/getting-started/)。

## 反馈问题时提供什么

提供操作步骤、当前分支与提交、工具版本、启动方式、失败请求的路径/HTTP 状态/业务错误码，以及脱敏后的相关日志。不要提供密码、token、Cookie、完整环境文件或数据库备份。

公共错误码统一见[接口规范](/standards/api#公共错误码)。[部署运维](/deployment/)与[发版与升级](/release/)目前保留待完善。
