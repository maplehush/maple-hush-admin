## 适用环境

本栏目面向 **Ubuntu 24.04 LTS 正式服务器**，覆盖测试环境与生产环境。测试环境用于发布前验证，生产环境用于正式使用；两者的访问入口、配置、凭据与业务数据需要隔离。

本地源码启动请阅读[快速开始](/getting-started/)。本栏目后续从一台新服务器开始介绍部署，不以读者已经安装 Docker 或配置网关为前提。
