# 快速开始

本章说明如何下载源码、准备开发环境并启动 Maple Hush Admin，最终完成管理员首次登录与改密。

假定你具备 Java、Vue 基础，并能在自己的系统中安装开发工具与管理 MySQL、Redis。本章不限定 Windows、Linux 或 macOS；存在命令差异时分别给出 PowerShell 和 Bash 示例。

## 本章采用的运行方式

- 前端：Vite 开发服务，默认端口 **5999**。
- 后端：在源码工程中通过 Maven Wrapper 打包，再运行 Jar，默认端口 **8080**。
- 数据服务：使用已经准备好的 MySQL 与 Redis，通过后端参数指定地址和凭据。
- 配置环境：使用 **dev**，不需要域名或 HTTPS 证书即可在本机开发。

```text
浏览器 http://localhost:5999
    → Vite 同源 /api 代理
    → 后端 http://127.0.0.1:8080
    → MySQL、Redis
```

这是本地开发流程。正式服务器的 Docker、Nginx、HTTPS 及环境隔离将在[部署运维](/deployment/)中补充。

## 开始前确认

- 当前使用一个新的开发数据库，或者清楚已有库的用途和管理员状态。
- 后端参数会在启动它的终端或 IDE 运行配置中设置；根目录 `.env` 不是源码启动的自动配置入口。
- OSS 可以稍后配置；未配置时不使用头像和文件上传，其他基础管理功能可以先启动。
- 命令中的示例路径、账号和密码必须替换为自己的实际值。

本章依据当前源码与配置整理。工程的版本及用途见[技术栈](/introduction/technology)，不同平台的安装方式以相应工具的官方说明为准。
