# T20 仓库根目录一键部署

**前置**：T18、T19。**范围**：仓库根目录统一编排和单侧启动入口。

## 实施

- [ ] 根 `docker-compose.yml` 通过 Compose `include` 组合子项目，服务名固定为 `frontend`、`backend`、`mysql`、`redis`；根 `.env.example` 提供非敏感部署变量，统一模式前端 upstream 指向 `http://backend:8080`。
- [ ] 支持仓库根目录 `docker compose up -d --build`、`docker compose up -d --build frontend`、`docker compose up -d --build backend`；不写固定 `container_name`、全局卷名或冲突端口。
- [ ] 验证两套同机部署时不同 `COMPOSE_PROJECT_NAME` 的 MySQL/Redis 隔离、宿主机端口区分和 OSS Bucket/前缀区分。根模式仅前端对外提供 HTTPS。

## 验收

- [ ] 三个目录的 `docker compose config` 均通过，根模式和两种单侧命令逐项演练；检查服务、网络、卷、变量和构建上下文。
- [ ] 根模式在预发布环境激活 `test` profile，使用隔离的 MySQL/Redis 数据与密钥，验证 HTTPS 首页、`/api` 冒烟、四服务健康状态、登录/refresh/退出、重建后的 MySQL 数据持久和 Redis 缓存重建；没有把“只启动前端”误认为已启动后端。记录 Compose 实际解析的 upstream、端口与密钥挂载路径；T21 再做完整首次部署、备份恢复和发布验收。
