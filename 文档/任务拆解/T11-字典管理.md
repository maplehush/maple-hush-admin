# T11 字典管理

**前置**：T06。**范围**：字典类型与字典项，不扩展系统参数管理。

## 实施

- [ ] 实现 `/api/system/dict/**` 类型/字典项的列表、详情、增改删及按类型查询；DTO/VO 与表实体分离。字典项管理和按类型查询均返回可选 `color`，供前端按字典值渲染状态标签。
- [ ] 字典项 `color` 仅接受空值或 `#RRGGBB` 格式（例如 `#52c41a`），大小写十六进制字符均可输入，保存前统一转为小写；它只控制展示，不参与字典项 `status` 的启停判断。
- [ ] 约束类型编码唯一、同一类型内字典值唯一；同一类型至多一个 `is_default=1`，切换默认项时锁定字典类型行并在同一事务内更新。处理类型删除与关联项的规则，输入校验和排序白名单落实在接口。
- [ ] 交付权限码、菜单节点、操作审计及真实 MySQL 测试。

## 验收

- [ ] 测试同类型重复值、不同类型相同值、并发切换默认项、删除关联、无权操作和前端所需查询响应；后端 `verify` 通过。
