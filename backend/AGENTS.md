# 后端工作指引

本目录由 T0 的 Spring Initializr Java 21、Spring Boot 4.1.1 工程改造而成；T02 已落地四模块公共底座，T03 已落地系统表与种子，T04 已落地首次认证流程，T05 已落地 V3 会话版本、refresh 轮换、退出、CSRF/来源检查和过期会话清理。T06 已落地有效权限计算、当前用户/权限码/动态菜单查询、授权版本失效辅助服务和操作审计底座。T07 已落地菜单管理树、增改删、查重及真实写操作审计；T08 已实现部门树、增改删、层级和关联删除保护及操作审计；T09 已实现角色分页/详情/增改删、菜单授权范围校验、内置保护和原持有者授权失效；T10 已实现用户分页/详情/增改删、角色分配和密码重置、唯一超管与目标角色范围保护、目标会话失效与审计；T11 已实现字典类型/项管理、颜色校验、默认项事务切换和关联删除保护及审计；其余管理接口仍待后续任务；不要把设计目录示例当成现有代码。先读[总体架构](../开发文档/架构设计/总体架构.md)、[后端项目结构](../开发文档/架构设计/后端项目结构.md)、[后端开发规范](../开发文档/开发规范/后端开发规范.md)及本轮[任务卡](../开发文档/任务拆解/README.md)。

- 后续 Maven 模块、依赖方向和包布局按后端项目结构实施；业务按功能分包，Controller → Service → Mapper，业务 Service 统一使用 `service/I...Service` 接口和 `service/impl/...ServiceImpl` 实现，调用方注入接口；事务和审计注解保留在实现类公共方法。Java 类名、字段、DTO/VO、注释、格式和测试遵循后端开发规范及本目录 `.editorconfig`。
- 对外 JSON、权限、时间格式、会话、Redis 和 OSS 约定见[前后端接口契约](../开发文档/接口契约/前后端接口契约.md)与总体架构。实际接口更改要同步文档和前端调用；不以 mock 形状代替产品契约。
- 配置按 `dev`、`test`、`prod` 区分；本地与 Compose 的地址通过环境变量覆盖。`dev` 的 MySQL `root/123456` 和 Redis `123456` 是用户批准的开发默认值，可由环境变量覆盖；`test/prod` 凭据必须从受控运行环境注入，其他密钥不得入 Git、镜像或日志。实际 Maven、数据库和容器验证要留下命令与结果，未执行则明确标记。


- JavaDoc 统一使用多行格式；实体、DTO/VO 组件、公共常量/错误码与 Service 契约补充有效业务说明。所有条件和循环的语句体必须写大括号，非空块按行展开；简单一次性逻辑优先留在 Service 私有方法，`support/` 仅承载复杂或复用的功能内辅助逻辑。
