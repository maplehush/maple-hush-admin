# 后端工作指引

本目录由 T0 的 Spring Initializr Java 21、Spring Boot 4.1.1 工程改造而成；T02 已落地四模块、单可执行 Jar、公共响应/异常、MyBatis-Plus、Redis 和环境配置；T03 已落地 Flyway V1/V2、11 张表、系统种子及六组实体/Mapper。认证与授权业务尚未实施；不要把设计目录示例当成现有代码。先读[总体架构](../开发文档/架构设计/总体架构.md)、[后端项目结构](../开发文档/架构设计/后端项目结构.md)、[后端开发规范](../开发文档/开发规范/后端开发规范.md)及本轮[任务卡](../开发文档/任务拆解/README.md)。

- 后续 Maven 模块、依赖方向和包布局按后端项目结构实施；业务按功能分包，Controller → Service → Mapper，单实现 Service 不强制抽接口。Java 类名、字段、DTO/VO、注释、格式和测试遵循后端开发规范及本目录 `.editorconfig`。
- 对外 JSON、权限、时间格式、会话、Redis 和 OSS 约定见[前后端接口契约](../开发文档/接口契约/前后端接口契约.md)与总体架构。实际接口更改要同步文档和前端调用；不以 mock 形状代替产品契约。
- 配置按 `dev`、`test`、`prod` 区分；本地与 Compose 的地址通过环境变量覆盖。`dev` 的 MySQL `root/123456` 和 Redis `123456` 是用户批准的开发默认值，可由环境变量覆盖；`test/prod` 凭据必须从受控运行环境注入，其他密钥不得入 Git、镜像或日志。实际 Maven、数据库和容器验证要留下命令与结果，未执行则明确标记。
