## 目标与已选方案

面向从 GitHub 下载本项目、具备 Java/Vue 基础的新使用者，提供介绍、源码启动和二次开发指导。技术采用 **VitePress + Markdown + TypeScript**，独立项目放仓库根 `docs/`，与 `frontend/`、`backend/` 同级。配置、依赖、锁文件和预览/构建命令独立于前端 workspace。

选型比较：VitePress 与现有 Vue/Vite 技术一致，适合 Markdown 使用手册；Docusaurus 适合 React 及多版本文档场景，当前不采用。首版中文，两个阅读路线为“使用项目”和“二次开发”。已确认设计见[文档站点规划](../文档站点规划.md)。
