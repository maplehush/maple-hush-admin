### 关键核对

1. 当前菜单权限码限定 system:resource:action，因此示例没有直接使用另一命名空间；明确白名单登记与资源重载步骤。
2. admin-notice-biz 单独声明 Security 与 provided Lombok；不误以为 core 的 provided Lombok 可以传递给新模块。
3. 根 modules 注册与 start 的运行依赖分开；api 是 Java 契约，不是 HTTP 服务；新模块不另建 main/重复分页插件。
4. 迁移使用实际未占用版本，HTTP ID 为 string、分页 items/total、DTO 全量写入；Wrapper-only 更新时间显式设置。
5. Page、useVbenVxeGrid、CellOperation/VbenTableAction、useVbenForm/useVbenDrawer、语言词条均按当前工程说明；抽屉详情失败不开放提交。
6. 公告纯文本不使用 v-html；权限由菜单/按钮显示与后端校验共同衔接，不添加匿名白名单。
