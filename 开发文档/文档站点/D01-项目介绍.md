### 核对依据及结果

1. 用 Node 读取前端 pnpm-lock.yaml 的对应 importer，去掉 peer dependency 后缀取得实际版本。18 项前端库/工具与正文比对通过；不能用 catalog 声明范围代替解析版本。
2. 在 backend，使用 JDK 21.0.12 执行：

```sh
./mvnw -o -B -ntp -pl admin-system-start -am dependency:tree -DoutputFile=target/d01-dependency-tree.txt -DoutputType=text
```

Windows 实际入口为 `mvnw.cmd`，结果 BUILD SUCCESS。四模块各自 target 下生成依赖树（忽略的本地核对产物）；启动模块树包含 Boot 4.1.1、Spring 7.0.9、Security 7.1.1、Flyway 12.4.0、MySQL Connector/J 9.7.0 等实际解析值。本命令只做依赖解析，不表示业务测试通过。

3. 按四个模块实际 POM 核对 start → biz、biz → core/api；api 无项目模块依赖。按文件系统核对目录和常用入口，修正前端配置文件名为 vite.config.ts。
4. MySQL 8.4、Redis 7.4 是 Compose 默认部署目标，正文单列历史本地版本，未公开虚拟机过程、IP 或截图。
5. 独立只读复核未发现版本、模块、目录或功能边界错误；没有扩大到历史部署配置改动。
