# 系统数据库表结构（设计草案）

本文把 [T03 第一份建库建表 SQL 草案](../任务拆解/T03-01-建库建表草案.sql) 中的 11 张表整理为字段表；[第二份系统基础数据 SQL 草案](../任务拆解/T03-02-系统基础数据草案.sql)展示内置角色、菜单、按钮和授权关系。T03 已将两份草案整理为后端工程中的 [Flyway V1](../../backend/admin-system-start/src/main/resources/db/migration/V1__create_system_tables.sql) 与 [Flyway V2](../../backend/admin-system-start/src/main/resources/db/migration/V2__seed_system_data.sql)，并在本机 MySQL 8.0.24 空库执行。默认开发库 `maple_hush_admin` 已迁移到 V2，仍无用户；首个管理员由 T04 显式开启的引导程序创建。

## 阅读约定

- 暂定 MySQL 8.4、InnoDB、`utf8mb4`。`BIGINT` 对应 Java `Long`；对外用户 ID 按 Vben 接口约定输出字符串。
- 时间列均为 `DATETIME`，精确到**秒**，按 `Asia/Shanghai` 解释。`DATETIME` 本身不带时区；`CURRENT_TIMESTAMP` 依赖 MySQL 会话时区。接口时间格式为 `yyyy-MM-dd HH:mm:ss`。
- “默认值/生成”中的 `—` 表示 SQL 没有显式默认值；可空列的隐式默认值为 `NULL`。`自增` 是生成方式，并非 `DEFAULT` 子句。
- `status` 统一为 `1` 启用、`0` 停用。下方约束与索引依 Flyway V1 记录，其他业务规则仍须由 Service 校验。
- Java 实体层由 `SysDept`、`SysUser`、`SysRole`、`SysMenu`、`SysDictType`、`SysDictItem` 继承只含 `createTime/updateTime` 的 `BaseEntity`；其余五张表只有 `create_time`，由各实体自行声明。该复用不改变以下数据库字段或建表 SQL。

## 1. `sys_dept`：系统部门

| 字段名 | 数据类型 | 可空 | 默认值/生成 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 否 | 自增 | 部门主键。 |
| `parent_id` | `BIGINT` | 是 | — | 上级部门 ID；根部门为 NULL。 |
| `name` | `VARCHAR(100)` | 否 | — | 部门名称。 |
| `sort` | `INT` | 否 | `0` | 同级部门排序值；升序排列，同值按 `id` 升序。 |
| `status` | `TINYINT` | 否 | `1` | 部门状态：1 启用，0 停用。 |
| `remark` | `VARCHAR(500)` | 是 | — | 备注。 |
| `create_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 创建时间。 |
| `update_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 更新时间；更新该行时自动刷新。 |

**约束与索引**：主键 `id`；`parent_id` 自引用外键，删除受引用部门时 `RESTRICT`；索引 `(parent_id, sort)`；`status` 限定为 0/1。深层循环及关联用户时的删除规则由 Service 校验。

## 2. `sys_user`：系统用户

| 字段名 | 数据类型 | 可空 | 默认值/生成 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 否 | 自增 | 用户主键。 |
| `dept_id` | `BIGINT` | 是 | — | 所属部门 ID；可暂未分配。 |

| `real_name` | `VARCHAR(100)` | 否 | — | 姓名；用户管理接口映射为 `name`，当前用户接口映射为 `realName`。 |
| `password` | `VARCHAR(255)` | 否 | — | 只存带盐的单向密码哈希，不存明文或可解密密文；不进入普通查询结果和 VO。 |
| `avatar_url` | `VARCHAR(1024)` | 是 | — | 后端生成的阿里云 OSS 头像 HTTPS URL。 |
| `introduction` | `VARCHAR(500)` | 是 | — | 用户本人可编辑的个人简介，与管理员备注分开。 |
| `status` | `TINYINT` | 否 | `1` | 用户状态：1 启用，0 停用。 |
| `must_change_password` | `TINYINT` | 否 | `1` | 是否必须修改临时密码：1 是，0 否。 |
| `auth_version` | `BIGINT` | 否 | `0` | 授权版本；授权或账号变更时递增，使旧令牌失效。 |
| `remark` | `VARCHAR(500)` | 是 | — | 管理备注。 |
| `create_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 创建时间。 |
| `update_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 更新时间；更新该行时自动刷新。 |

**约束与索引**：主键 `id`；`username` 唯一；`dept_id` 外键指向 `sys_dept.id`，删除受引用部门时 `RESTRICT`；索引 `(dept_id, status)`；`status`、`must_change_password` 限定为 0/1，`auth_version >= 0`。唯一超级管理员账号保护由 Service 实现，启动时校验内置角色恰有一条用户关联且关联用户已启用。删除普通用户前须撤销并清理其刷新会话与角色关联；登录、操作日志保留账号快照。

## 4. `sys_menu`：系统菜单与按钮

| 字段名 | 数据类型 | 可空 | 默认值/生成 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 否 | 自增 | 菜单节点主键。 |
| `parent_id` | `BIGINT` | 是 | — | 上级节点 ID；根节点为 NULL。 |
| `name` | `VARCHAR(100)` | 否 | — | 路由/菜单节点名称。 |
| `title` | `VARCHAR(200)` | 否 | — | 菜单展示标题；组装为 `meta.title` 的权威来源。 |
| `type` | `VARCHAR(16)` | 否 | — | 节点类型：catalog、menu、embedded、link、button。 |
| `path` | `VARCHAR(255)` | 是 | — | 按嵌套路由原样保存：根节点为绝对路径 `/system`，其子节点为相对路径 `user` 等；按钮节点必须为空。最终访问地址由父子路由拼接。 |
| `component` | `VARCHAR(255)` | 是 | — | Vben 页面组件键，如 `/system/user/list`，对应前端 `src/views/system/user/list.vue`；目录节点可以为空。 |
| `redirect` | `VARCHAR(255)` | 是 | — | 路由重定向目标。 |
| `auth_code` | `VARCHAR(120)` | 是 | — | 小写权限码；页面节点可填写对应查询码（如 `system:user:list`），按钮节点必填操作码，目录节点通常为空。 |
| `icon` | `VARCHAR(200)` | 是 | — | 菜单图标；组装为 `meta.icon` 的权威来源。 |
| `meta_json` | `JSON` | 是 | — | 其他白名单内的 Vben 路由元数据；不覆盖标题、图标和排序值。 |
| `sort` | `INT` | 否 | `0` | 同级节点排序值；升序排列，同值按 `id` 升序；组装为 `meta.order` 的权威来源。 |
| `status` | `TINYINT` | 否 | `1` | 节点状态：1 启用，0 停用。 |
| `create_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 创建时间。 |
| `update_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 更新时间；更新该行时自动刷新。 |

**约束与索引**：主键 `id`；`name`、非空 `auth_code` 全表唯一；`path` 在同一父节点下唯一（将根节点的 `NULL parent_id` 归一为 0 后建立唯一索引），按钮的 `NULL path` 不参与路径冲突；`parent_id` 自引用外键，删除受引用节点时 `RESTRICT`；索引 `(parent_id, sort)`；`type`、`status` 和按钮/非按钮的 `path` 条件受 `CHECK` 限制。Service 校验根节点使用绝对路径、子节点使用相对路径，并校验完整访问地址不冲突；T01 按实际前端版本复核。深层循环、按钮所属页面和角色授权的目录祖先由 Service 校验。

## 5. `sys_user_role`：用户角色关联

| 字段名 | 数据类型 | 可空 | 默认值/生成 | 说明 |
| --- | --- | --- | --- | --- |
| `user_id` | `BIGINT` | 否 | — | 用户 ID，指向 sys_user.id。 |
| `role_id` | `BIGINT` | 否 | — | 角色 ID，指向 sys_role.id。 |
| `create_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 角色授予时间。 |

**约束与索引**：复合主键 `(user_id, role_id)` 防止重复授予；两个字段分别有外键，删除受引用用户或角色时 `RESTRICT`；反向索引 `(role_id, user_id)`。`super_admin` 仅由首次引导写入一条关联；普通业务接口拒绝增删该关联，启动时校验数量与用户状态。

## 9. `auth_refresh_session`：刷新会话

| 字段名 | 数据类型 | 可空 | 默认值/生成 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | `BIGINT` | 否 | 自增 | 会话记录主键。 |
| `user_id` | `BIGINT` | 否 | — | 所属用户 ID。 |
| `family_id` | `CHAR(36)` | 否 | — | 轮换链令牌族 ID；ascii_bin 区分大小写。 |
| `token_hash` | `CHAR(64)` | 否 | — | Refresh Token 哈希；不保存原始 token，ascii_bin 区分大小写。 |
| `expire_time` | `DATETIME` | 否 | — | 令牌族绝对到期时间；同一族轮换生成的记录继承首次登录时的到期时间，不无限续期。 |
| `used_time` | `DATETIME` | 是 | — | 该 token 被轮换使用的时间。 |
| `revoked_time` | `DATETIME` | 是 | — | 被撤销时间；未撤销时为空。 |
| `create_time` | `DATETIME` | 否 | `CURRENT_TIMESTAMP` | 会话创建时间。 |

**约束与索引**：主键 `id`；`token_hash` 唯一；`user_id` 外键指向 `sys_user.id`，删除受引用用户时 `RESTRICT`；索引 `(user_id, expire_time)`、`family_id`、`expire_time`、`revoked_time`。轮换、撤销及重放检测由认证 Service 实现。默认令牌族有效期 7 天；已使用记录至少保留至该族到期，避免清理任务提前抹去有效期内的重放证据，随后按可配置留存期清理。
