# T06 接口权限与动态路由

**前置**：T05。**范围**：统一授权来源、接口鉴权、当前用户可见路由，以及后续管理写操作共用的最小操作审计写入能力。

## 实施

- [x] `sys_user_role`、`sys_role_menu`、`sys_menu` 为唯一授权来源；权限码全小写 `system:resource:action`。实现当前用户 `/api/user/info`、权限码 `/api/auth/codes`、路由树 `/api/menu/all`。权限码汇总获授且有效的页面/按钮节点；路由树过滤按钮节点并补齐获授页面的必要目录祖先，不因补齐祖先授予额外接口权限。`/api/menu/all` 的 `data` 按 Vben `RouteRecordStringComponent[]` 返回 `name/path/component?/redirect?/meta/children?`，不返回数据库 `id/pid/type/status/authCode` 或按钮节点。`sys_menu.path` 按嵌套路由原样保存和输出，例如根 `/system` 下的子节点 `user`，最终访问地址为 `/system/user`；`component` 使用无 `.vue` 后缀的页面键，T06 核对规划路径与数据形状，T14 建立目标应用 `src/views` 页面后验收解析加载。
- [x] `/api/**` 默认需认证；管理接口声明 `@PreAuthorize`，未认证返回 401、无权限返回 403。T03 预设的 `component` 先核对路径清单与响应形状，T14 建立对应最小页面组件后再验收浏览器加载；不能把未落地页面写成已可访问。
- [x] 角色、菜单授权变化时递增受影响用户的 `authVersion`；同一请求内复用授权查询结果。跨模块只暴露实际需要的 `admin-system-api` 只读契约。
- [x] `/api/user/info` 可读取 Redis 中的最小用户快照，缓存缺失时从 MySQL 重建；账号状态、令牌族和 `authVersion` 始终由 MySQL 校验。本人资料或授权变更后清理快照，版本不符不得使用旧缓存；权限码与菜单仍由 MySQL 授权关系计算。
- [x] 在 `admin-system-biz/log` 落地 `@OperationLog` 切面、`SysOperationLogService` 和 Mapper：成功审计在业务提交后以新事务写入，失败审计独立事务写入；摘要脱敏，写入失败可观察且不回滚已成功业务。T07 起每个管理写操作实际接入此能力；查询页面及保留清理由 T12 完成。

## 验收

- [x] 真实 MySQL 与 HTTP 测试覆盖不同角色的菜单树、按钮码、直接越权访问、401/403、授权变更后旧 token 失效；按 [Vben mock 菜单响应](../架构设计/总体架构.md#2-vben-联调契约)校验响应包装和当前用户路由树，确认按钮与管理字段不进入 `/api/menu/all`。
- [x] 审计基础能力测试覆盖业务提交、业务回滚、审计写入失败和敏感字段不入库；后续任务须验证各自写操作的实际日志。
- [x] 返回体与 [Vben 契约](../架构设计/总体架构.md#2-vben-联调契约)一致，后端 `verify` 通过。

## 执行记录（2026-10-14）

代码实现、只读审查与最终验证已完成；本轮仅执行 T06。

- 当前用户、有效权限码、动态菜单三个 GET 接口已实现。账号/会话/版本由 MySQL 校验，权限与菜单来自活跃角色的数据库关联，同次请求复用认证上下文；内置超管没有权限旁路。
- 页面和按钮码有效；孤立按钮、停用祖先、断链、循环不生效；目录补齐不扩权。路由只包含约定字段，元数据按实际 Vben 类型过滤，根目录缺省为 `BasicLayout`，七个系统页面键的真实加载仍留给 T14。
- `AuthorizationChangeService` 在管理业务事务内递增版本，提交后清理快照；角色/指定用户提供定向更新，菜单变更保守更新所有已分配角色的用户。删除关联前调用或先捕获受影响用户，避免漏掉原持有者。资料变更提供提交后清缓存辅助方法。
- `/api/user/info` 读取最小快照，核对用户 ID 与版本；缺失、损坏或 Redis 故障回退 MySQL 资料。快照 TTL 配置 `AUTH_USER_SNAPSHOT_TTL_SECONDS` 默认 600 秒。Redis 故障下验证码、登录、轮换仍维持拒绝/回滚规则。
- 操作审计采用 `spring-boot-starter-aspectj`，注解位于公共模块，切面/Service/Mapper 位于业务模块；固定摘要、不采集敏感载荷，记录路径模板与可选数值目标 ID。加入外层事务时等待其最终结果；审计写入及提交失败记录日志与失败计数。
- 目前没有跨模块消费者，`admin-system-api` 保留最小空契约入口。测试写接口只装配到测试上下文，T07 起真实写操作接入授权和审计。
- 本步不新增 Flyway 版本，开发库仍为 V3，未修改真实 `admin` 密码。
