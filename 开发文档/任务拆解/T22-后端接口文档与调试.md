# T22 后端接口文档与调试

## 状态与范围

2026-10-23 根据用户指令补录本轮实施记录。代码、配置和本地验证已交付；Apifox 云端整理及下列待确认项不标记为通过。本任务独立于 T18～T21 的容器和上线验收，不改变这些任务的未完成状态。

目标是在现有 Spring Boot 4.1.1、Java 21 工程中提供在线接口文档、统一错误码说明和认证调试入口，配合用户已安装的 IDEA Apifox Helper 使用。使用步骤统一维护在[后端接口文档与调试](../开发规范/后端接口文档与调试.md)，本卡记录实施和验收。

## 已实施内容

- 接入社区维护的 Knife4j Next 5.7.9 Boot4 Starter，配套 springdoc 3.0.3；没有使用原 Knife4j 4.5.0 Starter。
- 为 49 个业务接口补充中文分组、接口说明、参数及模型说明；补充文件上传和 refresh 返回值的真实契约。
- 文档配置和启动日志位于 `admin-system-start` 的 `com.maplehush.admin.config.docs`，由启动模块负责应用级装配；文档访问策略由业务安全链执行。
- dev/test 默认开放文档，prod 关闭；混合 profile 包含 prod 时也拒绝访问。不放宽业务权限、Cookie 来源及 CSRF 校验。
- 配置普通 Bearer、首次改密凭据及 Cookie 会话调试说明，refresh/logout 标注 CSRF 请求头。
- 首页集中列出成功码及全部 11 个非零错误码，不向每个接口重复注入通用错误响应；按用户要求移除首页“登录过期如何判断”段落。
- ApplicationReadyEvent 后打印带分隔线的启动成功提示，Knife4j 与 OpenAPI 链接分别独占一行，名称与链接同行。地址采用实际端口、协议及上下文路径；文档关闭时保留启动成功提示，不打印文档链接。
- Controller 类注释首行统一为短分组名；增加 `.apifox-helper.properties`，配置读取接口摘要、忽略标有 `@ignore` 的测试辅助 Controller。插件上传建议只选择 `admin-system-biz/src/main/java`；未代替用户修改 Apifox 云端数据。
