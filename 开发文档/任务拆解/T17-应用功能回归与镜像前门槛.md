# T17 应用功能回归与镜像前门槛

**前置**：T01～T16。**范围**：对已完成的首版应用功能做独立回归，为 T18、T19 构建镜像提供基线；容器、TLS、Compose 和首次部署的最终验收在 T20、T21。

## 实施

- [ ] 后端 `verify` 必须运行 Failsafe 的 `*IT`；集成测试激活 `test` profile，连接隔离的真实 MySQL 与 Redis，覆盖 Flyway 空库/升级、Mapper、事务、HTTP 契约、Boot/MyBatis-Plus/Redis 兼容、验证码一次性消费、限流、登录快照失效与缓存重建。
- [ ] 前端运行目标应用 typecheck、build，并做浏览器端到端冒烟；核对登录、验证码、强制改密、角色权限、七个系统页面、个人中心与头像。
- [ ] 复核唯一超管保护与内置角色并发授予拦截、维护模式恢复原超管及旧会话失效、页面/按钮授权闭包、越权授权、401/403、同页及同源多标签页并发刷新、旧 refresh 重放与令牌族绝对到期、access 过期时凭有效 refresh Cookie/CSRF 退出、Cookie/CSRF、审计脱敏、OSS 上传/清理和无密钥/远程 mock 混入应用产物。
