# T15 前端系统管理页面

**前置**：T07～T12、T14。**范围**：`web-antdv-next` 的七个系统页面。

## 实施

- [ ] 参考锁定版本的 `playground`，将用户、角色、菜单、部门页面及 API 适配到 `apps/web-antdv-next`；按本项目接口新增字典、登录日志、操作日志页面。
- [ ] 在 T14 建立的真实 `component` 路径上完成七个页面，移除所有“待实现”最小入口内容；用 T01 接口契约清单逐页核对请求/响应、错误处理和权限码，不另造一套路由路径。
- [ ] 字典项表单提供可选颜色选择器，提交 `#RRGGBB`；业务页面在需要展示状态时，按字典值读取 `label/color` 渲染标签或状态标记，`color` 为空时使用普通样式。前端也要校验颜色格式，并按背景色选择可读的文字颜色；字典项启停仍以 `status` 判断，不以颜色判断业务状态。
- [ ] 实际路由 `component`、分页 `items/total`、表单 DTO 和按钮权限码逐一与后端核对。管理树与当前用户动态路由分开，角色表单提交菜单节点 ID；用户角色选择不提供内置 `super_admin`，唯一超管账号的停用、删除、列表重置及角色编辑入口不可操作，后端同时拒绝直调。页面查询权限、按钮操作权限、目录祖先和无权直调 API 同时验证。
- [ ] 页面里不增加岗位、参数、代码生成或与目标系统无关的演示功能；无权限按钮隐藏，直调 API 的拒绝由后端保证。

## 验收

- [ ] 浏览器从菜单进入七个页面，完成各自查询和受支持的写操作；不同角色看到不同菜单和按钮。
- [ ] 执行目标应用 typecheck、build 和浏览器联调；网络面板无 mock 或重复 `/api` 前缀。
