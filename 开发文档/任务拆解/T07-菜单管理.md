# T07 菜单管理

**前置**：T06。**范围**：系统菜单管理树及其路由/按钮规则。

## 实施

- [ ] 实现 `/api/system/menu/**` 的管理树、增改删、名称/路径查重；支持 `catalog/menu/embedded/link/button`。`/api/system/menu/list` 的 `data` 对齐 Playground `SystemMenu` 管理树，含字符串 `id/pid`、`name/type/status/path?/component?/authCode?/meta/children?`，保留按钮；与 `/api/menu/all` 的用户路由树使用不同 VO。
- [ ] 校验父子关系、路由组件路径、权限码和删除关联；数据库根节点 `path` 使用绝对路径，子节点使用相对路径，同级路径不得重复，并核对拼接后的完整访问地址不冲突。管理树对路由节点输出完整 `path`，新增/修改也接受完整 `path` 并结合 `pid` 转成数据库相对路径；`path-exists` 只接收完整路径及可选当前 `id`，按完整访问地址查重，与 Playground 表单调用一致。页面节点可带对应查询权限码，按钮节点必须带操作权限码；按钮须归属页面，目录节点不因包含页面而获得接口权限。`title/icon/sort` 分别生成 `meta.title/icon/order`，`meta_json` 只接受其余白名单字段。同级节点按 `sort ASC, id ASC` 稳定排序。新增节点同步处理内置超管授权，变更菜单授权、节点状态或权限码后更新受影响用户 `authVersion`。
- [ ] 交付 Controller、DTO/VO、Service、Mapper、权限声明，并把关键写操作接入 T06 已落地的操作审计；用真实数据库测试。
- [ ] 菜单变更导致授权版本变化时清理受影响用户的 Redis 快照；MySQL `authVersion` 仍为旧 token 失效依据。

## 验收

- [ ] 测试重复名称/完整路径、非法层级、相对路径与管理树完整路径的往返、按钮仅出现在管理树、无权管理被拒绝、权限变更使旧 token 失效。
- [ ] 后端 `verify` 通过；管理树和当前用户路由树返回符合 Vben 调用契约。
