# T19 前端镜像与独立部署

**前置**：T17。**范围**：`frontend/` 自己能构建并服务目标应用静态文件。

## 实施

- [ ] 原位改造 Vben `scripts/deploy/Dockerfile`、`nginx.conf`、`build-local-docker-image.sh`：构建 `@vben/web-antdv-next`，运行时使用 `apps/web-antdv-next/dist`，保留 SPA fallback；脚本使用锁文件安装且不先删除旧镜像。
- [ ] 编写 `frontend/docker-compose.yml`、`.env.example`、`.dockerignore`；Nginx 代理 `/api` 到可配置的已部署后端，生产使用 HTTPS 和同源 Cookie 行为。
- [ ] 不复用上游面向 `playground` 的 FTP 工作流；前端镜像不包含演示应用、源码密钥或远程 mock 地址。

## 验收

- [ ] 在 `frontend/` 执行 `docker compose config` 和 `docker compose up -d --build`；浏览器验证 SPA 刷新、`/api` 代理、登录刷新及静态产物来源。
- [ ] 独立前端需连接已运行的后端；未具备外部后端时只报告镜像构建/静态服务结果，不报告完整登录通过。
