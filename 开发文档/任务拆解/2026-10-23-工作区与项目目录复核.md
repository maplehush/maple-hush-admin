本轮按用户要求再次整理工作区和产品仓库；只调整目录、工程元数据和说明，不改接口与业务逻辑。

- 文档首页更新为源码实际包含的 Flyway V1～V10，并修正“T21 未实施”的过期描述；不据源码版本推定运行数据库已完成迁移。
- 工作区 AGENTS.md 补充产品仓库、参考代码、Git 历史目录及历史片段的用途，避免再次产生重复路径。

## 目录处理结论

| 位置 | 处理及理由 |
| --- | --- |
| 工作区 `.vscode/`、`.editorconfig`、`AGENTS.md` | 保留，分别服务工作区编辑器、格式约束及工作指引 |
| `参考代码/` | 保留，为用户指定的上游参考源码和历史片段，不是产品代码 |
| `references/*.git/` | 保留，包含 Git 对象、索引和分支历史，不能按文件名当普通缓存删掉 |
| 产品仓库 `.git/`、`.github/`、`.vscode/` | 保留，分别是版本历史、产品 CI 和共享编辑器配置 |
| `frontend/apps/web-antdv-next/`、`packages/`、`internal/`、`scripts/` | 保留，属于目标应用及 workspace 构建依赖 |
| `frontend/apps/backend-mock/` | 当前只作参考且目标应用已关闭 Mock；按现有指引保留，本轮不扩展为依赖裁剪任务 |
| 前端 `.changeset/`、lint/format/TS/Vite/Turbo 配置 | 保留，现有命令仍在使用；不能只因是点目录就删除 |
| `node_modules/`、`dist/`、后端各模块 `target/` | 可重新生成；本轮保留正常依赖和产物，避免影响正在使用的开发或演练服务 |
| 后端 `.mvn/`、mvnw、四个模块、迁移 SQL | 保留，属于构建链和产品源码；历史迁移不能删除或重编号 |
| `.env`、`secrets/`、IDE 本地配置、部署与运维目录 | 保留；凭据不查看或写入本记录，正式运行配置不可按临时文件清理 |
| `开发文档/` | 保留，历史任务卡记录当时状态，当前导航维护现状；不批量删除实施证据 |

## 后续可优化项

1. 如需进一步缩小前端 workspace，可单独实施 backend-mock 及专用依赖裁剪，须核对 Nitro/Mock 插件和安装锁文件后验证目标应用。
2. 产品构建与验证已由根 CI 管理；真实 OSS、Docker、公网 HTTPS 以及远程 CI 的环境验收，仍按原任务待办执行，目录清理不能替代这些验收。
3. Git Hooks 的安装入口仍继承上游 monorepo 约定，产品仓库比前端多一层目录；后续如要启用提交门禁，应专项核对安装位置和命令工作目录，避免误生成根目录示例配置。

## 验证范围

本轮检查编辑器入口存在性、工程 JSON 解析、项目仓库地址、归档内容哈希、配置格式和 Git 差异；不重复执行 Maven、数据库迁移、前端构建或部署，不将昨日结果标为本轮通过。
