# T11 字典管理

**前置**：T10（含 T06 授权/审计底座与 T09/T10 写锁查询）。**范围**：字典类型与字典项，不扩展系统参数管理。

## 实施

- [x] 实现 `/api/system/dict/**` 类型/字典项的列表、详情、增改删及按类型查询；DTO/VO 与表实体分离。字典项管理和按类型查询均返回可选 `color`，供前端按字典值渲染状态标签。
- [x] 字典项 `color` 仅接受空值或 `#RRGGBB` 格式（例如 `#52c41a`），大小写十六进制字符均可输入，保存前统一转为小写；它只控制展示，不参与字典项 `status` 的启停判断。
- [x] 约束类型编码唯一、同一类型内字典值唯一；同一类型至多一个 `is_default=1`，切换默认项时锁定字典类型行并在同一事务内更新。处理类型删除与关联项的规则，输入校验和排序白名单落实在接口。
- [x] 交付权限码、菜单节点、操作审计及真实 MySQL 测试。

## 验收

- [x] 测试同类型重复值、不同类型相同值、并发切换默认项、删除关联、无权操作和前端所需查询响应；后端 `verify` 通过。

## 本轮实施安排（2026-10-14）

1. 先编写真实 HTTP/MySQL 字典测试，验证未实现端点失败。
2. 实现字典 DTO/VO、`ISysDictService`/`SysDictServiceImpl`、Controller 与 Mapper；不新增系统参数功能或 support 类。
3. 字典写入沿用已有授权写锁与操作者版本复核，再锁所属类型行；默认项切换在同一事务清旧置新，失败整体回滚。
4. 专项及全量后端回归、独立审查，更新接口契约、架构、交接及任务状态。

裁定：类型编码创建后不可变；字典项不通过更新移动到其他类型。类型包含任何字典项（含停用项）时拒绝删除。删除默认项后允许无默认项，不自动选取其他项；停用不自动改变 defaultItem，普通编码查询只返回启用类型下的启用项。原始类型不存在返回 404，停用类型普通查询返回空数组。

表单更新为全量文本资料；状态/排序/默认标记省略时保留原值，可空颜色/备注为空时显式清除。颜色允许 null、空字符串或六位 HEX，保存转小写。排序仅接收 sortBy/sortOrder 白名单，所有列表稳定追加 ID 排序。复用 V1/V2/V3 与现有字典菜单/权限种子，不新增迁移。

进度：T11 已完成。11 个端点、10 个真实专项测试、全量 clean verify 及独立静态审查均已完成。
